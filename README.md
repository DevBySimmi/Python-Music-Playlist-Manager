# 🎵 Python Music Playlist Manager

A simple and modern **Music Playlist Manager** desktop application built with **Python and Tkinter**.

This application allows users to create, manage, search, shuffle, and save their music playlists through a clean and easy-to-use interface.

---

## ✨ Features

- ➕ Add songs to playlist
- 🗑️ Remove selected songs
- ⏮️ Previous song
- ⏭️ Next song
- 🔀 Shuffle playlist
- 🔍 Search songs
- 💾 Save playlist to a file
- 📂 Load playlist from a file
- 🧹 Clear entire playlist
- 📊 Total songs counter
- 🎶 Current song display
- 🌙 Modern dark-themed interface
- 🚫 No external packages required

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random
- File Handling
